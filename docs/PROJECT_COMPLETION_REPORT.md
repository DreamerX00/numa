## 🔧 Technical Details

### Technology Stack
- **Framework**: Next.js 15.5
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Database**: Prisma + MongoDB
- **Images**: Next.js Image + Cloudinary

### Component Architecture
```
Component: MostLovedProductsCarousel
├── Props: { products: Product[] }
├── State: 
│   ├── currentIndex (number)
│   ├── itemsPerView (number)
├── Effects:
│   └── Responsive resize listener
├── Handlers:
│   ├── goToPrevious()
│   ├── goToNext()
├── Render:
│   ├── Header (centered)
│   ├── Carousel (motion-animated)
│   ├── Navigation (arrows)
│   ├── Indicators (dots + counter)
│   └── CTA button
```

### Animation System
- **Carousel Scroll**: Spring physics (stiffness: 300, damping: 30)
- **Image Hover**: Scale 1.0 → 1.1 (300-700ms)
- **Card Lift**: Y-axis: 0 → -8px (300ms)
- **Entrance**: Staggered 50ms delays
- **Badge**: Spring entrance animation
